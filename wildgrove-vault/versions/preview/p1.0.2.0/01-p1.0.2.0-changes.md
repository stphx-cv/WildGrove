# p1.0.2.0

Fecha: 2026-10-08 · Nivel: Ajuste

## Qué cambió

### Reglas
- Hay una regla nueva sobre la memoria de los agentes: lo que un agente aprende se guarda dentro del proyecto y no en la memoria propia de su herramienta. Lo que no puede subirse a GitHub va en la carpeta privada, y los datos personales no se guardan en ninguna memoria.
- La regla de versionado dice que el campo del commit vale solo «done» o «pending», sin el hash.
- La regla de Git explica que este clon tiene su propia identidad de Git y que no hay que quitarla.

### Documentación
- Hay un documento nuevo, «Cómo verificar un cambio en local», con las técnicas para comprobar un cambio contra la pila local sin tocar producción.
- El índice de reglas, el de referencia y la guía para agentes enlazan los dos documentos nuevos.

## Por qué
Lo que los agentes iban aprendiendo estaba guardado fuera del proyecto, donde ningún otro agente ni persona podía leerlo. Ahora vive en el repositorio, o en la carpeta privada cuando no puede publicarse.

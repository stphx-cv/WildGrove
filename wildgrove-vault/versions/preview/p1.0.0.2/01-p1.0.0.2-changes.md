# p1.0.0.2

Fecha: 2026-10-04 · Nivel: Retoque

## Qué cambió

### Reglas
- Subir una versión incluye crear su release en GitHub, en la misma secuencia que el commit, el push y la etiqueta. Antes la release era un paso aparte y se podía quedar sin hacer.

## Por qué
Una versión sin release no aparece en la página de releases, que es lo primero que mira quien entra en el repositorio.

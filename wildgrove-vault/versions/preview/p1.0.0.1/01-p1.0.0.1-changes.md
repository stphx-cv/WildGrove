# p1.0.0.1

Fecha: 2026-10-04 · Nivel: Retoque

## Qué cambió

### El repositorio
- El repositorio se llama `wildgrove`, en minúsculas. El enlace al código de las páginas legales y de la superficie para agentes, y las instrucciones para clonarlo, usan el nombre nuevo. Las direcciones con el nombre anterior siguen llevando al mismo sitio.

## Por qué
El nombre en minúsculas es el mismo que llevan las imágenes del registro y la carpeta del almacén.

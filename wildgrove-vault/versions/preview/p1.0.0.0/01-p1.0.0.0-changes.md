# p1.0.0.0

Fecha: 2026-10-04 · Nivel: Estructura

## Qué cambió

### Wild Grove, publicado
- Un restaurante ficticio construido entero como pieza de portafolio, en línea y en uso, con el código abierto bajo licencia MIT. La marca y las fotos no entran en la licencia.

### La tienda
- En español y en inglés: la carta con sus filtros y sus descuentos, el carrito sin necesidad de cuenta, los pedidos a recoger o a domicilio con boleta o factura, las reservas, las reseñas del local y de cada plato, el contacto y la cuenta de cada cliente.
- Se paga con una billetera interna. Cada cuenta nueva recibe un saldo de prueba para poder hacer un pedido de verdad.

### Sage
- Un asistente virtual en el chat de la tienda que enseña la carta, comprueba disponibilidad, reserva y responde sobre el local. Un modelo de decisión elige qué hacer antes de que otro modelo escriba la respuesta, y los platos y los precios los pone siempre el código.
- El chat puede estar apagado, atendido solo por el personal, solo por Sage, o por los dos.

### El panel
- Para el personal: la carta con sus borradores, los pedidos, las reservas, las billeteras, los clientes, las reseñas, los tickets, el chat, las zonas de reparto, los descuentos y todos los ajustes de la tienda.

### Para agentes de IA
- Una API pública de solo lectura, un servidor MCP, cualquier página en markdown pidiéndola así, y los documentos de descubrimiento que la acompañan.

### La documentación
- Cómo está construido, el modelo de datos, qué hace el producto, el sistema de diseño, la API, las variables de entorno, las decisiones con sus alternativas descartadas y la guía de la voz de la marca.
- Las reglas de trabajo del repositorio, para personas y para agentes de IA.

## Por qué
El proyecto sale a la luz con un historial que empieza aquí. Esta es la primera versión pública, y las siguientes cuentan lo que cambia a partir de ella.

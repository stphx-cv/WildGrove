# Commit de p1.0.0.0

## Título

```
p1.0.0.0
```

## Descripción

```
[+] Tienda pública en español e inglés, con rutas traducidas
[+] Carta por categorías, con etiquetas dietéticas y una página por plato
[+] Precios en soles y en dólares, fijados a mano para cada plato
[+] Descuentos automáticos con fecha de inicio y de fin
[+] Carrito sin necesidad de cuenta, que se conserva al registrarse
[+] Pago con billetera interna y saldo de prueba para cada cuenta nueva
[+] Pedidos a recoger o a domicilio, con zonas de reparto y pedido mínimo
[+] Boleta y factura con sus series, y comprobante en PDF
[+] Seguimiento de pedidos, cancelación con reembolso y reactivación
[+] Reservas por franjas, con cupo, horario y cambio de fecha desde la cuenta
[+] Reseñas del local y de cada plato, con fotos y moderación
[+] Formulario de contacto con seguimiento de cada consulta
[+] Cuenta con perfil, direcciones, billetera, historial y acceso con Google
[+] Correos en los dos idiomas para pedidos, reservas, consultas y cuenta
[+] Tema claro, oscuro o el del sistema
[+] Sage, el asistente virtual del chat, que responde en el idioma de quien escribe
[+] Un modelo de decisión elige qué hacer antes de que otro modelo escriba
[+] La carta, los platos y los precios del chat los pone siempre el código
[+] Reservas, disponibilidad y promociones desde el chat
[+] 4 modos de chat: apagado, solo el personal, solo Sage o los dos
[+] Panel de administración, solo para los roles ADMIN y OWNER
[+] Acceso al panel con correo o con Google
[+] Escritorio con finanzas, operación, salud del sistema, productos y clientes
[+] Carta con borradores que se publican cuando están listos
[+] Gestión de pedidos, reservas, billeteras, clientes y reseñas
[+] Consultas de soporte y chat en vivo con los clientes
[+] Zonas de reparto, descuentos, notificaciones y ajustes de la tienda
[+] API pública de solo lectura y versionada para agentes de IA
[+] Servidor MCP con 4 herramientas de solo lectura
[+] Cualquier página pública en markdown, pidiéndola con la cabecera Accept
[+] llms.txt, openapi.json y documentos de descubrimiento en .well-known
[+] Monorepo con 2 aplicaciones de Next.js 16 y 3 paquetes compartidos
[+] Toda la lógica de negocio en un solo paquete que usan las 2 aplicaciones
[+] Esquema de Prisma 7 sobre PostgreSQL, con 30 tablas
[+] Componentes, iconos y tokens de diseño compartidos
[+] Política de dependencias contra paquetes comprometidos
[+] Política de seguridad de contenido en las 2 aplicaciones
[+] Límites de peticiones en el chat y en el acceso
[+] Compilación en GitHub Actions contra una base de datos desechable
[+] Imágenes de contenedor para la tienda, el panel y las migraciones
[+] Despliegue sin cortes: la versión nueva se comprueba antes de recibir tráfico
[+] Documentación de arquitectura, datos, funciones, diseño, API y entorno
[+] Las decisiones del proyecto con sus alternativas descartadas
[+] Guía de la voz de la marca
[+] Reglas de trabajo para personas y para agentes de IA
[+] Licencia MIT, sin la marca ni las fotos
```

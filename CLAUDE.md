# Instrucciones

**Lee `wildgrove-vault/rules/00-rules-index.md` antes de empezar cualquier tarea.** Es corto, y es el único sitio donde viven las reglas de este repositorio.

Después lee `AGENTS.md`, que tiene la forma del proyecto y la tabla que dice qué documento cubre el área en la que vas a trabajar.

Este archivo no contiene ninguna regla propia. Si una regla pertenece a este proyecto, su sitio es `wildgrove-vault/rules/`.
